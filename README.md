# 织文插件市场

织文输入法的公开扩展仓库。基础输入与原生模块仍由主程序提供；这里分发主题、手机布局及独立的 Lua 语音适配器。

- `catalog.json`：市场目录，主题与布局带文件大小和 SHA-256。
- `themes/`：11 个附加主题，亮暗两套配色。
- `layouts/`：5 个手机布局；默认主题由布局 JSON 声明。
- `plugins/http-pcm/`：通用 HTTP PCM 语音适配器，需要用户自己的兼容服务，不包含识别模型、服务账号或凭据。
- `docs/plugin-host.md`：Lua 宿主 API；`docs/offline-translation-plugins.md`：平台翻译扩展协议。

## 在织文中使用

支持在线市场的版本可在「插件市场 → 刷新」读取本仓库。网络不可用时，应用内目录仍可使用。
也可下载主题／布局 JSON，在「插件市场 → 导入」中安装；先安装布局声明的默认主题。

语音插件仓库建议填写 `https://github.com/sheep-programmer/weavetext-market/tree/main/plugins`，只扫描语音插件目录。
源代码导入后，在插件配置中填写自己的服务地址与可选令牌。

## 扩展边界

拼音、双拼、英文、候选、符号、光标编辑与剪贴板属于基础输入；这里不替换输入内核。
附加主题、布局和语音适配器可独立安装。候选学习、纠错、触摸响应等核心体验由主程序优化。

本仓库代码与资源采用 Apache-2.0。第三方贡献需说明来源、许可、平台和依赖，不提交密钥、用户输入或识别模型。
